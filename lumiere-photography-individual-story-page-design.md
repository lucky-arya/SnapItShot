# Lumière Photography — Individual Photograph / Story Page Design

## 01. Purpose

The Individual Story page is the deepest visual experience in the Lumière website.

It represents one complete photographic story, project, shoot, or curated photo essay.

Example URLs:

```text
/work/quiet-morning
/work/rajasthan-light
/work/between-ceremonies
/work/streets-of-old-delhi
```

This page should feel less like a portfolio item and more like opening a beautifully designed photography book.

The core principle:

> **The story belongs to the photographs. The interface exists only to guide the visitor through them.**

---

# 02. Experience Direction

The page should feel:

- cinematic
- intimate
- slow
- editorial
- immersive
- spacious
- human
- premium

Avoid:

- conventional product-page layouts
- thumbnail-heavy interfaces
- excessive buttons
- boxed content
- card grids
- unnecessary animations
- aggressive transitions

---

# 03. Story Page Structure

Recommended structure:

```text
GLOBAL NAVIGATION
        ↓
STORY HERO
        ↓
STORY INFORMATION
        ↓
OPENING IMAGE
        ↓
INTRODUCTION
        ↓
IMAGE SEQUENCE
        ↓
TEXT / IMAGE MOMENT
        ↓
FULL-BLEED FEATURE
        ↓
IMAGE SEQUENCE
        ↓
FINAL IMAGE
        ↓
STORY DETAILS
        ↓
PREVIOUS / NEXT STORY
        ↓
GLOBAL FOOTER
```

---

# 04. Story Hero

The hero should immediately establish the mood.

Use one powerful photograph.

Recommended height:

`85–100vh`

Desktop:

```text
┌───────────────────────────────────────────────┐
│                                               │
│                                               │
│                                               │
│                  HERO IMAGE                   │
│                                               │
│                                               │
│                                               │
│  QUIET MORNING                                │
│  OLD DELHI · INDIA                            │
└───────────────────────────────────────────────┘
```

Do not place excessive information over the image.

---

# 05. Hero Navigation

Use the established global navigation.

Desktop:

```text
← WORK / COLLECTIONS       LUMIÈRE       INQUIRE →
```

Mobile:

```text
← WORK              LUMIÈRE              ☰
```

The left navigation should return to the appropriate parent context.

For example:

```text
← PORTRAITS
```

when the story belongs to the Portraits collection.

---

# 06. Story Hero Typography

Bottom-left:

```text
01 / STORY

QUIET MORNING

OLD DELHI · INDIA
2025
```

Title:

- serif
- approximately `72–110px` desktop
- `46–60px` mobile

Metadata:

- uppercase sans-serif
- small
- generous letter spacing

Keep the title short.

Ideal:

`QUIET MORNING`

Avoid:

`A Beautiful Morning I Spent Photographing the Streets of Old Delhi`

The latter belongs in the narrative.

---

# 07. Story Metadata

The story can include:

```text
LOCATION
Old Delhi, India

DATE
January 2025

CATEGORY
Travel

PHOTOGRAPHY
Lumière Photography
```

On desktop, use a compact metadata row.

Example:

```text
LOCATION          DATE              CATEGORY
OLD DELHI         JAN 2025          TRAVEL
INDIA
```

On mobile, stack the metadata vertically.

---

# 08. Opening Statement

After the hero, return to the cream background.

Large whitespace.

Then:

```text
01 / THE STORY

Some mornings arrive quietly.

Before the streets become crowded,
before the city begins moving,
there is a brief moment when
everything feels still.
```

The statement should be approximately:

`40–120 words`

Do not turn every story into a long article.

---

# 09. Story Introduction Layout

Desktop:

```text
                    THE STORY

          Some mornings arrive quietly.

          Before the streets become
          crowded, there is a brief
          moment when everything feels still.

                                      SHOT IN
                                      OLD DELHI
```

Use asymmetric alignment.

The text should occupy approximately:

`4–5 columns`

while the remaining space stays intentionally empty.

---

# 10. First Image Sequence

After the introduction, begin the photographic sequence.

Do not immediately create a dense gallery.

Use:

```text
TEXT
↓
large whitespace
↓
IMAGE
↓
small whitespace
↓
IMAGE
↓
larger whitespace
↓
IMAGE
```

The spacing itself creates rhythm.

---

# 11. Image Sequence Types

Use several image formats.

## Portrait

Approximately:

`4:5`

Best for:

- people
- details
- emotional moments

## Landscape

Approximately:

`3:2`

Best for:

- environments
- streets
- scenes

## Wide Cinematic

Approximately:

`2:1` to `3:1`

Best for:

- atmosphere
- landscapes
- transitions

## Full Bleed

`100vw`

Best for:

- emotional peaks
- major moments

---

# 12. Editorial Image Placement

Do not center every photograph.

Use controlled asymmetry.

Example:

```text
                      ┌───────────────┐
                      │               │
                      │    IMAGE      │
                      │               │
                      └───────────────┘


┌──────────────────────┐
│                      │
│       IMAGE          │
│                      │
└──────────────────────┘


             ┌────────────────────────┐
             │                        │
             │       WIDE IMAGE       │
             │                        │
             └────────────────────────┘
```

This creates a sense of movement.

---

# 13. Image + Text Composition

At one or two carefully selected points, combine photography and narrative.

Example:

```text
┌───────────────────────────┐
│                           │
│                           │
│          IMAGE            │
│                           │
└───────────────────────────┘

                         I wanted to
                         photograph
                         the quiet
                         before the
                         city woke up.
```

Text should never compete with the photograph.

Keep it short:

`20–60 words`

---

# 14. Full-Bleed Emotional Moment

Every major story should have one defining image.

Use:

```text
┌──────────────────────────────────────────────┐
│                                              │
│                                              │
│                                              │
│                FULL IMAGE                    │
│                                              │
│                                              │
│                                              │
└──────────────────────────────────────────────┘
```

Height:

`70–95vh`

No unnecessary overlay.

Optional caption below:

```text
THE CITY BEFORE IT WAKES
OLD DELHI · 06:12 AM
```

This should be the visual climax.

---

# 15. Photography Captions

Captions should be rare.

Use them only when they add context.

Examples:

```text
OLD DELHI
06:12 AM
```

or:

```text
THE LAST LIGHT
RAJASTHAN · 2025
```

Typography:

- 10–12px
- uppercase
- letter spacing
- secondary color

# 17. Story Length

Recommended:

`8–20 photographs`

For a major project:

`15–30 photographs`

Do not publish every frame from a shoot.

The story should be edited.

The visitor should feel that each photograph has a reason to exist.

---

# 18. Final Photograph

End the image sequence with a photograph that feels quieter than the climax.

Avoid ending with the most dramatic image.

The final photograph should create a feeling of completion.

Example:

```text
                 ┌────────────────────┐
                 │                    │
                 │    FINAL IMAGE     │
                 │                    │
                 └────────────────────┘
```

Then leave substantial whitespace.

---

# 19. Story Details

After the final image:

```text
THE STORY

January 2025

```

Optional short closing note:

`A morning spent walking without a destination.`

Keep this section quiet.

# 24. Mobile Typography

Story title:

`44–60px`

Section heading:

`30–42px`

Narrative:

`17–19px`

Metadata:

`10–12px`

Captions:

`10–12px`

Line-height should remain generous.

---

# 25. Tablet Layout

Tablet should retain the editorial character without extreme desktop offsets.

Use:

- full-width hero
- asymmetric text
- two-column image arrangements
- full-width feature images
- simplified story navigation

Avoid complicated masonry.

---

# 26. Image Interaction

Desktop hover can show:

```text
VIEW
```

or:

```text
OPEN
```

inside a restrained cursor.

Image scale:

`1.01–1.02`

Avoid larger zoom effects because this page already contains significant motion through scrolling.

---

# 27. Lightbox — Optional

A lightbox can be available for visitors who want to inspect photographs closely.

Recommended behavior:

- click image
- image expands
- dark/near-black viewing environment
- previous/next controls
- close button
- image counter

Example:

```text
01 / 14

                         ×
```

The lightbox should not be the primary experience.

The editorial page remains the main experience.

---

# 28. Lightbox Mobile

Use:

- swipe left/right
- visible close button
- image counter
- tap controls

Do not hide the close control.

---

# 29. Scroll Reveal

Use extremely subtle reveals.

Recommended:

- opacity
- 8–16px vertical movement
- 400–700ms

Images:

- fade
- tiny upward movement

Text:

- fade + 8px movement

Avoid:

- dramatic scale
- blur-to-sharp transitions
- aggressive parallax
- scroll-triggered text transformations

---

# 30. Reduced Motion

When reduced motion is enabled:

Disable:

- image reveal movement
- page transitions
- parallax
- image zoom
- staggered text animation

Keep content immediately visible.

---

# 31. Story Loading

Prioritize:

1. Hero
2. First content image
3. First visible image sequence

Lazy-load the rest.

Use:

- AVIF
- WebP
- responsive image sizes

Maintain intrinsic aspect ratios.

Never allow images to cause large layout shifts.

---

# 32. Story Content Model

Each story should conceptually contain:

```text
Story
├── title
├── slug
├── hero image
├── collection
├── location
├── date
├── introduction
├── narrative sections
├── image sequence
│   ├── image
│   ├── caption
│   ├── location
│   └── sequence type
├── featured image
├── closing note
├── previous story
└── next story
```

This structure allows the photographer to control the editorial sequence without redesigning the page.

# 34. Story SEO

Each story should have unique:

- title
- meta description
- canonical URL
- Open Graph image
- social preview
- descriptive image alt text

Example:

```text
/work/quiet-morning
```

Page title:

`Quiet Morning — Lumière Photography`

---

# 35. Accessibility

Required:

- semantic headings
- keyboard-accessible navigation
- descriptive image alt text
- visible focus states
- accessible lightbox controls
- Escape to close lightbox
- screen-reader-friendly previous/next labels
- reduced-motion support

Decorative images should not create unnecessary screen-reader noise.

---

# 36. Performance

The story page can contain many large images, so performance is critical.

Use:

- responsive image `srcset`
- lazy loading
- optimized image formats
- CDN delivery
- compression
- intrinsic dimensions
- preload only the hero image

Do not preload every photograph.

---

# 37. Navigation Relationship

The visitor should always understand where they are.

Breadcrumb-like context can remain subtle:

```text
WORK / PORTRAITS / QUIET MORNING
```

Do not use a large traditional breadcrumb component.

On desktop it can appear near the story title.

On mobile:

```text
PORTRAITS
```

is enough.

---

# 38. Story Page Emotional Arc

A strong story should follow:

```text
ARRIVAL
   ↓
CONTEXT
   ↓
OBSERVATION
   ↓
INTIMACY
   ↓
CLIMAX
   ↓
REFLECTION
   ↓
DEPARTURE
```

Translate this visually:

```text
Hero
↓
Introduction
↓
Small images
↓
Closer images
↓
Full-bleed feature
↓
Quiet final images
↓
Next story
```

This is what separates an editorial story from a simple gallery.

# 40. Final Creative Principle

The Individual Story page should feel like a **photographic essay**, not a project management page.

The hierarchy must remain:

```text
PHOTOGRAPH
     ↓
EMOTION
     ↓
STORY
     ↓
WHITESPACE
     ↓
INTERFACE
```

The visitor should be able to forget that they are using a website.

They should feel like they are moving through a sequence of photographs.

The final experience should be:

**cinematic, quiet, intimate, editorial, human, and immersive.**
