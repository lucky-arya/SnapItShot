# Lumière Photography Website --- Introduction / Manifesto Section

**Project:** Lumière Photography Website\
**Section:** Introduction / Manifesto\
**Design Direction:** Editorial Luxury Photography / Modern Cream
Minimalism\
**Document Version:** 1.0\
**Status:** Design Specification --- Ready for UI Implementation

------------------------------------------------------------------------

# 1. Section Overview

The Introduction section is the first section immediately after the
fullscreen Hero.

The Hero creates an emotional first impression through photography.

The Introduction explains the photographer's **visual philosophy**.

The visitor should not feel that they have entered a conventional
"About" section. Instead, this section should feel like the beginning of
a conversation about how the photographer sees the world.

### Narrative progression

``` text
HERO
Emotion
   ↓
INTRODUCTION
Perspective
   ↓
SELECTED WORK
Proof
```

### Core idea

> **The Hero asks the visitor to look. The Introduction explains why the
> photographer looks the way they do.**

-   Editorial
-   Warm
-   Sophisticated
-   Artistic

-   Human
-   Thoughtful
-   Minimal
-   Premium

It should deliberately contrast the Hero.

## Hero

-   Fullscreen
-   Cinematic
-   Darker
-   Image dominant
-   Immersive

## Introduction

-   Cream
-   Spacious
-   Typography dominant
-   Editorial
-   Calm


Recommended alternatives:

The background should be warm rather than pure white.

The background should feel like a high-quality art book page.

# 9. Primary Photograph

The primary photograph is a vertical editorial image.

### Recommended aspect ratio

Approximately:

``` text
3:4
```

or:

``` text
4:5
```

The exact ratio depends on the source photograph.

## Image characteristics

The image should:

-   Feel intimate
-   Have natural light
-   Match the Hero's color grading
-   Contain visual depth
-   Have a clear focal point
-   Work with the warm cream background
-   Avoid excessive saturation

------------------------------------------------------------------------

# 10. Image Treatment

Use the image naturally.

Avoid:

-   Drop shadows
-   Thick frames
-   Rounded cards
-   Gradient borders
-   Decorative filters

The photograph should feel like it is physically placed on the page.

### Optional treatment

A very subtle film grain may be used if the rest of the site uses the
same photographic treatment.

Consistency is more important than adding effects.

------------------------------------------------------------------------

# 11. Image Position

The image sits toward the left/center of the section.

It should not be perfectly aligned with the page's global center.

A slight offset creates editorial character.

Example:

``` text

      IMAGE

                TEXT
```

This creates an asymmetric visual rhythm.

# 36. Scroll Reveal Animation

The section should animate when entering the viewport.

Recommended sequence:

### Stage 1 --- Image

Starts:

-   Slightly transparent
-   Slightly blurred
-   Approximately 10--20px lower

Then:

-   Sharp
-   Full opacity
-   Original position

### Stage 2 --- Headline

Reveals:

-   Opacity: `0 → 1`
-   Translate Y: approximately `20–35px → 0`

### Stage 3 --- Divider

Fades/extends into place.

### Stage 4 --- Supporting copy

Fades upward.

### Stage 5 --- CTA

Appears last.

------------------------------------------------------------------------

# 37. Animation Timing

Suggested:

``` text
Image:
700–1000ms

Headline:
600–800ms

Divider:
400–600ms

Body:
500–700ms

CTA:
500–700ms
```

Stagger the elements rather than animating everything simultaneously.

------------------------------------------------------------------------

# 38. Animation Easing

Use calm easing.

Good direction:

-   Ease-out
-   Cubic ease-out
-   Smooth custom editorial curve

Avoid:

-   Bounce
-   Elastic
-   Overshoot
-   Fast spring effects

The section should feel like it is quietly revealing itself.

# 45. Accessibility

The section must remain accessible.

### Images

If the image communicates meaningful information, provide useful
alternative text.

If it is purely decorative, it should not create unnecessary
screen-reader noise.

### Text

Maintain sufficient contrast.

### CTA

The entire CTA must be keyboard accessible.

### Focus

Use a visible focus state.

### Motion

Respect `prefers-reduced-motion`.

------------------------------------------------------------------------

# 46. Reduced Motion

When reduced motion is enabled:

Disable:

-   Blur-to-sharp animation
-   Parallax
-   Large image scale effects
-   Staggered motion

Use:

-   Simple fade
-   Static layout
-   Instant or near-instant reveal

The visual hierarchy must remain identical.

------------------------------------------------------------------------

# 47. Performance

The primary image is likely one of the largest assets in the section.

Use:

-   Responsive image sizing
-   Modern image formats
-   Appropriate compression
-   Correct intrinsic dimensions
-   Lazy loading where appropriate
-   Avoid oversized source images

The image should never be downloaded at a resolution far beyond what the
viewport requires.

# 55. UX Intent

The visitor should leave this section understanding three things:

### 1. Photography is intentional

The photographer isn't simply recording events.

### 2. Emotion matters

The purpose is to preserve how an experience felt.

### 3. There is more to explore

The CTA encourages deeper discovery.

------------------------------------------------------------------------

# 56. What This Section Should NOT Become

Do not turn this into:

-   A resume
-   A biography
-   A list of achievements
-   A services section
-   A company description
-   A large text wall
-   A conventional "About Us" card
-   A three-column content grid

Those elements belong elsewhere.

# 59. Final Design Principle

The section should communicate:

> **Photography is not about documenting everything. It is about
> noticing what deserves to be remembered.**

The design should therefore remain quiet enough for the visitor to slow
down.

The Hero captures attention.

The Introduction creates meaning.

The Selected Work section will provide evidence.

That gives the website a deliberate narrative rather than a collection
of disconnected sections.
