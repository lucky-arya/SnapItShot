# Lumière Photography Website --- About Photographer Section

**Project:** Lumière Photography Website\
**Section:** About Photographer\
**Section Number:** 05 / 06\
**Design Direction:** Editorial Personal Story / Modern Cream
Minimalism\
**Document Version:** 1.0\
**Status:** Design Specification --- Ready for UI Implementation

------------------------------------------------------------------------

# 1. Section Overview

The About Photographer section introduces the person behind the
portfolio.

The preceding Featured Photograph section focuses on one visual moment.

This section changes the emotional direction from:

``` text
THE IMAGE
    ↓
THE STORY
    ↓
THE PERSON
```

The visitor should begin to understand:

-   Who the photographer is
-   How they approach photography
-   What they value
-   Where they work
-   What types of photography they create
-   Why the visitor may want to explore further

This should **not** feel like a résumé or corporate About page.

It should feel like a personal editorial profile.

------------------------------------------------------------------------

# 2. Core Design Principle

The section should communicate:

> **There is a person behind every photograph.**

The design should be:

-   Human
-   Warm
-   Quiet
-   Authentic
-   Editorial
-   Sophisticated
-   Personal
-   Spacious

Avoid making the section feel overly polished or corporate.

The photographer's personality should be visible.

------------------------------------------------------------------------

# 10. Photographer Portrait

The photographer portrait is the primary visual element.

It should be a genuine portrait of the photographer.

Recommended characteristics:

-   Natural light
-   Environmental context
-   Authentic expression
-   Editorial composition
-   Slightly candid
-   Warm or neutral grading

Avoid:

-   Generic corporate headshots
-   Overly staged poses
-   Artificial studio backgrounds
-   Heavy retouching
-   Excessive skin smoothing

------------------------------------------------------------------------

# 11. Portrait Image Ratio

Recommended:

``` text
3:4
```

or:

``` text
4:5
```

The portrait should be vertical.

The exact crop should be chosen based on the photographer's actual
image.

------------------------------------------------------------------------

# 12. Portrait Position

The portrait should sit slightly off-center.

Avoid placing it exactly in the middle of the entire section.

The goal is to create an editorial asymmetric layout.

Conceptually:

``` text
LABEL
  ↓

       [ PORTRAIT ]

                    [ PHILOSOPHY ]
```

This creates visual tension while maintaining balance.

------------------------------------------------------------------------

# 13. Portrait Image Treatment

No decorative card styling.

Avoid:

-   Drop shadows
-   Thick frames
-   Rounded cards
-   Borders
-   Gradient frames

The photograph should simply exist on the cream page.

Optional:

-   Subtle film grain
-   Natural warm grading

# 49. Copywriting Guidelines

The homepage biography should be:

-   First person
-   Honest
-   Short
-   Personal
-   Specific
-   Emotionally grounded

Avoid:

> "I am a passionate professional photographer with years of experience
> providing high-quality photography solutions."

Prefer:

> "I'm drawn to honest moments, natural light, and the stories that
> unfold quietly around us."

The language should sound like a person, not a company.

------------------------------------------------------------------------

If the photographer has important credentials, they may appear as a tiny
secondary line.

Examples:

``` text

```

------------------------------------------------------------------------

# 51. Services Reference

The About section should not become a service list.

If needed, show only a compact specialty line:

``` text
PORTRAITS · WEDDINGS · TRAVEL · EDITORIAL
```

Detailed services belong in the Services section or Contact flow.

------------------------------------------------------------------------

# 52. Accessibility

Requirements:

-   Portrait has meaningful alt text.
-   Decorative secondary images should not create unnecessary
    screen-reader noise.
-   CTA is keyboard accessible.
-   Focus state remains visible.
-   Text has sufficient contrast.
-   Signature should not be the only way the photographer's name is
    communicated.
-   Metadata must remain readable at mobile sizes.

------------------------------------------------------------------------

# 53. Focus State

Interactive CTA should use a visible focus outline.

Recommended:

``` text
2px outline
2–4px offset
```

Do not remove the browser's focus indication without replacing it.

------------------------------------------------------------------------

# 54. Reduced Motion

When reduced motion is enabled:

Disable:

-   Blur-to-sharp transitions
-   Parallax
-   Signature drawing animation
-   Large image scaling
-   Line-by-line movement

Use:

-   Simple fade
-   Minimal translation
-   Static signature
-   Immediate content availability

------------------------------------------------------------------------

# 55. Performance

The portrait is a prominent image and should load efficiently.

Use:

-   Responsive image sizes
-   Modern formats
-   Proper compression
-   Intrinsic dimensions
-   Prioritized loading if the section is near the viewport
-   Lazy loading if the section is sufficiently below the fold

Avoid downloading an oversized original portrait.

------------------------------------------------------------------------

# 63. UX Intent

The visitor should leave this section understanding:

### 1. There is a real person behind the work

The portrait creates human connection.

### 2. The photographer has a defined philosophy

The headline communicates a point of view.

### 3. The photographer is approachable

The first-person copy creates intimacy.

### 4. There is more to discover

The About CTA opens the complete story.

------------------------------------------------------------------------

# 64. What This Section Should NOT Become

Do not turn it into:

-   A résumé
-   A LinkedIn profile
-   A list of awards
-   A corporate About Us page
-   A long autobiography
-   A services table
-   A skills list
-   A large credentials wall
-   A generic headshot card

The homepage should create curiosity.

The dedicated About page can provide depth.

# 68. Final Design Formula

``` text
Warm cream background
        +
Real photographer portrait
        +
Large editorial philosophy
        +
Short personal biography
        +
Authentic signature
        +
Minimal personal details
        +
Quiet CTA
```

The section should feel like opening the first page of the
photographer's personal journal.

------------------------------------------------------------------------

# 69. Final Design Principle

> **Show the person, not the résumé.**

The visitor has already seen the photography.

Now they should understand the person who made it.

The visual journey becomes:

``` text
THE WORK
     ↓
THE MOMENT
     ↓
THE PERSON
     ↓
THE CONVERSATION
```

That final transition leads naturally into the last homepage section:

**06 / CONTACT --- Let's Create Something Together.**
