# Lumière Photography — Full About Page Design

## 01. Purpose

The About page introduces the person behind Lumière.

The homepage About section creates curiosity.

The full About page creates connection.

Its purpose is not to function like a résumé or professional profile. It should answer:

- Who is the photographer?
- What do they see?
- Why do they photograph?
- How do they work?
- What kind of stories do they care about?
- Where are they based?
- How can someone work with them?

The visitor should leave feeling that they know the person behind the photographs.

---

# 02. Core Direction

The About page should feel:

- personal
- editorial
- warm
- honest
- cinematic
- understated
- human
- premium

Avoid:

- corporate biography layouts
- résumé-style timelines
- skill bars
- excessive statistics
- generic “about me” cards
- fake testimonials
- unnecessary equipment lists
- stock photography

The photographer should remain the subject.

---

# 05. Hero Layout — Desktop

Use an asymmetric two-column composition.

Approximate structure:

```text
┌────────────────────────┐ ┌────────────────────────────┐
│                        │ │                            │
│                        │ │ ABOUT                      │
│                        │ │                            │
│      PORTRAIT          │ │ THE PERSON                 │
│                        │ │ BEHIND THE                 │
│                        │ │ PHOTOGRAPHS.               │
│                        │ │                            │
│                        │ │ Short introduction         │
│                        │ │                            │
└────────────────────────┘ └────────────────────────────┘
```

Image:

approximately `45%`

Text:

approximately `55%`

Do not use equal columns.

---

# 06. Hero Image

The photographer's portrait should feel natural.

Recommended:

- environmental portrait
- natural light
- neutral or real working environment
- genuine expression
- editorial composition
- minimal retouching

Preferred aspect ratio:

`4:5`

or

`3:4`

Avoid:

- corporate headshots
- artificial studio backgrounds
- excessive skin retouching
- overly dramatic posing

The photograph should communicate personality.

---

approximately `18–22px`.

# 08. Introduction

After the hero, create a large breathing space.

Then:

```text
01 / A LITTLE ABOUT ME

I photograph people, places and
the quiet moments that connect them.

My work is driven by light, emotion
and the feeling that exists between
what happens and what is remembered.
```

Recommended length:

`70–140 words`

Write in first person.

The tone should be conversational and confident, not promotional.

---

# 09. Personal Philosophy

This should be one of the largest typography moments on the page.

Example:

```text
I LOOK FOR
THE MOMENTS
BETWEEN
THE MOMENTS.
```

or:

```text
I AM LESS
INTERESTED IN
PERFECT PICTURES
AND MORE
INTERESTED IN
```

Use only one primary philosophy statement.

It should feel authentic to the photographer.

# 11. Photographer Portrait Interlude

Introduce a second image.

This does not need to be another formal portrait.

Possible images:

- photographer working
- holding a camera
- walking through a location
- preparing for a shoot
- reviewing photographs
- candid working moment

This makes the page feel lived-in.

Recommended placement:

Large image offset from the main grid.

# 12. The Journey

Avoid a conventional vertical résumé timeline.

Instead use a short editorial story.

Heading:

```text
THE JOURNEY
```

Then:

```text
It started with curiosity.

Then came the camera.

Then the realization that
photography wasn't really about
owning a camera at all.

It was about learning to notice.
```

Continue with the photographer's real story.

Recommended:

`150–300 words`

Keep paragraphs short.

# 14. Photography Approach

This section explains how the photographer works.

Heading:

```text
HOW I WORK
```

Do not use feature cards.

Instead use three editorial principles.

### 01 — OBSERVE

I take time to understand the people, place and atmosphere before reaching for the photograph.

### 02 — WAIT

The best moments are often not scheduled. I leave room for them to happen.

### 03 — PRESERVE

The final photograph should feel like a memory rather than a performance.

These are examples and should be rewritten to match the photographer's actual philosophy.

---


- large number

- short paragraph
- generous whitespace

```text
I spend time watching
before I start directing.
```

# 20. Optional Hover Preview

Desktop-only enhancement.

When hovering:

```text
PORTRAITS →
```

a small image can appear near the cursor.

The image should:

- remain small
- move subtly
- never obstruct the text
- disappear immediately when the cursor leaves

Do not use this interaction on mobile.

Possible:


Do not turn this into a personal résumé.

---

# 22. Equipment Section — Optional

Equipment should not be a major part of the About page.

If included, place it near the bottom.

Example:

```text
THE TOOLS

CAMERA
SONY / CANON / FUJIFILM

LENSES
35MM · 50MM · 85MM

PROCESS
DIGITAL · FILM
```

The exact information should reflect the photographer's real equipment.

Avoid a giant gear list.

The work matters more than the gear.

---

# 23. Behind-the-Scenes Gallery

Optional but strongly useful.

Create a small visual sequence:

```text
BEHIND THE WORK

[ IMAGE ]       [ IMAGE ]

             [ LARGE IMAGE ]
```

These can show:

- shooting
- travel
- preparation
- editing
- locations
- quiet personal moments

This makes the About page feel human.

---

# 24. Testimonials — Optional

Testimonials should not dominate the page.

If included, use only authentic client feedback.

Editorial format:

```text
“Short genuine testimonial
about the experience.”

CLIENT NAME
PROJECT TYPE
```

Avoid:

- star ratings
- review cards
- large testimonial carousels

The testimonial should support the human story rather than turn the page into a sales page.

---

# 25. Press / Recognition — Optional

# 31. Tablet Layout

Tablet should simplify the asymmetric desktop design.

Use:

- portrait + text stacked where necessary
- two-column image compositions
- centered philosophy statement
- three approach principles in a horizontal or stacked arrangement

Avoid trying to preserve every desktop offset.

---

# 33. About Page Image Interaction

Photography interactions remain subtle.

Hover:

- scale `1.01–1.02`
- slight opacity overlay only when needed
- optional `VIEW WORK →`

Avoid turning every image into an interactive object.

Some images should simply exist.

---

# 34. Scroll Animation

Use subtle reveals:

- opacity
- 8–16px vertical movement
- 400–700ms

Recommended sequence:

```text
section enters
↓
headline appears
↓
supporting text appears
↓
image enters
```

Do not animate every paragraph independently.

---

# 35. Reduced Motion

With reduced motion enabled:

Disable:

- image scale
- parallax
- staggered text
- hover preview movement
- page transitions

Content remains visible and usable.

---

# 36. Accessibility

Requirements:

- semantic headings
- logical heading hierarchy
- descriptive image alt text
- keyboard-accessible links
- visible focus indicators
- adequate color contrast
- no information conveyed by animation alone
- reduced-motion support

The page should still communicate the photographer's story without photographs.

---

Recommended page:

```text

```

Unique:

- page title
- meta description
- Open Graph image
- canonical URL
- photographer name
- location
- relevant structured metadata where appropriate

Suggested title pattern:

```text
About [Photographer Name] — Lumière Photography
```

The About page can conceptually contain:

```text

├── photographer name
├── hero portrait
├── introduction
├── philosophy
├── working portrait
├── journey
├── approach
│   ├── observe
│   ├── wait
│   └── preserve
├── signature statement
├── location
├── availability
├── specialties
├── optional equipment
├── behind-the-scenes gallery
├── optional recognition
└── inquiry CTA
```

This allows the page to grow without changing its core design.

---

# 39. What Should NOT Be On The About Page

Avoid:

- skill percentage bars
- generic software lists
- giant résumé timeline
- unrelated hobbies
- fake statistics
- exaggerated claims
- excessive awards
- stock images
- huge equipment catalogs
- multiple competing CTAs
- generic “I am passionate about photography” copy

Every element should reveal something meaningful.

---

# 40. Final About Page Experience

The visitor should move through:

```text
WHO I AM
   ↓
WHAT I SEE
   ↓
WHY I PHOTOGRAPH
   ↓
HOW I WORK
   ↓
WHERE I WORK
   ↓
WHAT I PHOTOGRAPH
   ↓
LET'S CREATE
```

The page should feel like a conversation with the photographer.

---

# 41. Final Creative Principle

The About page should not try to prove that the photographer is talented.

The photographs already do that.

Instead, the page should reveal:

**the eye, personality, values, and perspective behind the photographs.**

The final feeling should be:

**personal, authentic, editorial, warm, quiet, confident, and human.**
